# Tech Stack
## ArenaMind

### Core
- **Framework:** Symfony 6.4 (WebApp Pack)
- **Language:** PHP 8.1+

### Database
- **RDMS:** MySQL 8
- **ORM:** Doctrine ORM

### Frontend
- **Templating:** Twig
- **Styling:** Tailwind CSS (via AssetMapper or Webpack Encore)
- **JS:** Stimulus (Part of Symfony UX)

### DevOps / Tools
- **Version Control:** Git
- **Dependency Manager:** Composer
- **Environment:** Docker (optional but recommended)
